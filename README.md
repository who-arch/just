An ultra-premium, dark-mode, full-featured **GitHub Clone & AI Developer Platform** — 100% client-side, running entirely in your browser with IndexedDB + LocalStorage persistence. Zero backend. Zero API keys. Deploys anywhere.

## ✨ Features

- 🔐 **Full Auth System** — Instant account creation, profile customization, follow system
- 📊 **365-Day Contribution Heatmap** — Auto-updates on every commit, issue, or repo creation
- 📦 **Repository Engine** — Public/private repos, fork with full history, star, watch
- 🌿 **Real Git** — Branches, SHA-1 commit hashes, side-by-side diff viewer, commit timeline
- 📝 **Monaco Editor** — VS Code engine with full syntax highlighting and autocomplete
- 🗂️ **File Manager** — Nested folders, upload local files, download any repo as `.zip`
- 🐛 **Issues & PRs** — Markdown threads, color-coded labels, comments
- 🎨 **Live Sandbox** — Renders any repo with `index.html` inside a sandboxed iframe
- 🤖 **Keyless AI Copilot** — Commit messages, README generation, code explainer, repo chat (Ctrl+I)
- 🎯 **Command Palette** — Ctrl+K for instant navigation
- 🔌 **Plugin System** — Drop a file in `/modules/`, add to manifest, auto-registers route + UI
